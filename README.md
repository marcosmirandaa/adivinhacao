# Guessing Game

An initial project using Python to start my journey into development and technology.

## How it works

The program picks a random number between 1 and 100. You have 7 attempts
to guess it, and after each guess you get a hint: higher or lower.
It also tells you when you run out of attempts.

## How to run

You need Python 3 installed. In the project folder, run:

```
python adivinhacao.py
```
